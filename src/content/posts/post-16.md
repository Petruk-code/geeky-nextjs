## Fitur Unggulan QGIS

- Analisis kontur dan cut-fill untuk pekerjaan tanah
- Import data dari AutoCAD, Excel, dan GPS survey
- Plugin ekstensi untuk analisis hidrologi dan drainase
- Simbologi dan layout peta siap cetak

<Notice type="info">
  QGIS 100% legal dan bebas royalti — aman dipakai untuk proyek profesional maupun tugas kuliah.
</Notice>

## Cara Download dan Install

1. Klik tombol download di bawah
2. Pilih installer sesuai sistem operasi (Windows 64-bit)
3. Jalankan installer dan ikuti panduan hingga selesai
4. Tambahkan plugin pendukung lewat menu *Plugins → Manage*
