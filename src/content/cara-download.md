Semua file yang dibagikan di situs ini diunggah ke layanan penyimpanan cloud seperti Google Drive atau MEGA agar aman dan cepat. Berikut langkah-langkah mengunduhnya.

## Langkah 1: Klik Tombol Download

Setiap artikel download memiliki tombol hijau di bagian akhir. Klik tombol tersebut untuk menuju ke halaman penyimpanan file.

<Button href="/kontak">Tidak Menemukan Tombol Download?</Button>

## Langkah 2: Tunggu Halaman Hosting Terbuka

Setelah diklik, kamu akan diarahkan ke Google Drive atau MEGA. Cari tombol *Download* atau ikon panah ke bawah di pojok kanan atas layar.

<Notice type="info">
  Jika kamu belum login ke akun Google, kamu mungkin diminta masuk terlebih dahulu — file tetap bisa diunduh tanpa biaya.
</Notice>

## Langkah 3: Antivirus Terkadang Memperingatkan

Beberapa file installer sering dianggap sebagai false positive oleh Windows Defender atau antivirus lain. Jika peringatan muncul:

1. Pastikan kamu mengunduh dari tombol resmi di artikel
2. Klik *More info* lalu *Run anyway* pada Windows SmartScreen
3. Cek hash file di artikel untuk memastikan keasliannya

<Notice type="warning">
  Selalu bandingkan ukuran file di artikel dengan ukuran file hasil unduhan. Jika berbeda jauh, file mungkin rusak atau belum terunduh sempurna.
</Notice>

## File Berformat ZIP atau RAR

Sebagian besar file kami bagikan dalam format ZIP agar ukurannya lebih kecil. Untuk membukanya gunakan aplikasi seperti WinRAR atau 7-Zip. Jika file dilindungi password, password selalu tertera di artikel masing-masing.

## Cara Download di HP

Situs ini juga bisa diakses dari HP. Pada Android, unduhan otomatis tersimpan di folder *Download* dan bisa dibuka dengan aplikasi pengelola file. Untuk iOS, file ZIP otomatis tersimpan di aplikasi *Files*.
